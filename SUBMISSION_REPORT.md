# SUBMISSION REPORT

## Task 2: Predictive Modeling Using Machine Learning

### 1. Project Title
Customer Purchase Prediction Using Machine Learning

### 2. Objective
The objective of this task is to build a supervised machine learning model that predicts whether a customer is likely to purchase a product based on age and estimated salary.

### 3. Algorithms Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

### 4. Process
The dataset was prepared and explored before dividing it into training and testing sets. Multiple supervised learning models were trained and their accuracy was compared. The best-performing model was further evaluated using a confusion matrix, classification report, ROC curve, and ROC-AUC score.

### 5. Tools and Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, and Streamlit.

### 6. Expected Outcome
The completed project demonstrates the ability to train supervised machine learning models, compare their performance, evaluate predictions, and use a trained model to make predictions for new customer data.

### 7. Deliverables
- Jupyter Notebook
- Streamlit prediction application
- README documentation
- Requirements file
- Submission report
