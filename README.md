# Task 2 - Predictive Modeling Using Machine Learning

## Project Title
**Customer Purchase Prediction Using Machine Learning**

## Objective
Build a supervised machine learning model to predict whether a customer is likely to purchase a product based on age and estimated salary.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Machine Learning Models
1. Logistic Regression
2. Decision Tree
3. Random Forest

## Workflow
1. Create and inspect the dataset
2. Check missing values and statistics
3. Visualize the data
4. Split data into training and testing sets
5. Scale features for Logistic Regression
6. Train three supervised learning models
7. Compare model accuracy
8. Evaluate the best model with a confusion matrix
9. Generate an ROC curve and AUC score
10. Make a sample prediction

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Classification Report
- ROC Curve
- ROC-AUC
